Estudos_NoSQL

Repositório da disciplina de NoSQL. Uso para guardar as anotações das aulas, os comandos do MongoDB no mongosh e os exercícios.

Arquivos:

CRUD.NoSQL.js — comandos do MongoDB reunidos em um só arquivo: criação de banco e collection, CRUD (insert, find, update, delete) e relacionamentos (one-to-one, one-to-many e many-to-many, embarcados e por referência)
atividade_pratica.js — exercícios "Antes e Depois" com o banco store e a collection customers, mais a seção de desafio
JAVA_SpringBoot.md — anotações sobre API REST com Java e Spring Boot: conceitos, configuração do projeto, camadas (Model, Controller, Service e Repository) e CRUD completo
imagens/ — imagens usadas nas anotações
